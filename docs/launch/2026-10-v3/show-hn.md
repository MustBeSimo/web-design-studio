# Show HN: Web Design Studio 3.0, three small web design skills

I made Web Design Studio, a free MIT collection for coding agents. One skill plans a page's message and proof, one builds cinematic websites, and one audits an authorised page's scroll experience. No Web Design Studio account or key is required.

Install and select a skill:
npx skills add MustBeSimo/web-design-studio

The old install pulled a 393 MB tree and was still cloning after 150 seconds. This release separates small text-only skill folders from the showcase; cinematic-scroll is about 30 KB.

What we checked: historical reference fixtures, verifier failure paths and five FIELD browser profiles. A three-build comparison on one brief found no correctness advantage for the skill. No larger head-to-head benchmark has been run, and these checks do not establish better design or conversion.

Evidence: https://github.com/MustBeSimo/web-design-studio/blob/main/docs/skill-advantage/README.md

Try the 28 live examples: https://mustbesimo.github.io/web-design-studio/

I would welcome reports of unclear instructions, broken installs and outputs where the skill did not help.
