An agent skill should not take minutes to install. Web Design Studio's old install pulled a 393 MB tree and was still cloning after 150 seconds. The showcase had become part of the installation problem.

---

Web Design Studio 3.0.0 separates three text-only skills from the showcase. The main skill folder is about 30 KB. Install and choose what you need:

npx skills add MustBeSimo/web-design-studio

---

cinematic-scroll builds the site.

Try: "Use cinematic-scroll to build a product story with one scroll reveal. Keep my brand and supplied copy. Verify mobile and reduced-motion states."

---

scroll-audit reviews an existing page.

Try: "Use scroll-audit to review my site's scroll experience. Score pacing, performance, accessibility and emotional arc. Write remediation-plan.md with the highest-impact fix first."

---

launch-page-strategy decides what the page must say.

Try: "Use launch-page-strategy to plan my waitlist page. Choose one action, map objections to evidence and write a story brief. Do not invent proof."
