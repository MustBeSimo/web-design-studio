Web Design Studio 3.0.0 makes the install smaller and the work easier to choose.

The previous installer pulled a 393 MB tree and was still cloning after 150 seconds. The new path selects text-only skill folders; cinematic-scroll is about 30 KB.

Three skills, three jobs:
• launch-page-strategy decides what the page must say and prove.
• cinematic-scroll builds a distinctive website using your brand and content.
• scroll-audit reviews an authorised page and writes a scored remediation plan.

Install:
npx skills add MustBeSimo/web-design-studio

The collection is free and MIT-licensed, with no Web Design Studio account or key needed.

The evidence has limits. Our three-build comparison on one brief found no correctness advantage for the skill. This release improves distribution; it does not claim better generated results.
