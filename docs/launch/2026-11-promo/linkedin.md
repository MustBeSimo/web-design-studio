A product story should look and move like the product it explains.

I built Web Design Studio to give coding agents a reusable process for that work: understand the brief, shape the art direction, build a meaningful interaction, then inspect the result in the browser.

Three free, open-source skills:

- launch-page-strategy plans what a page should say, prove and ask visitors to do.
- cinematic-scroll builds the website around your brand, content and existing stack.
- scroll-audit reviews an existing page and prioritises improvements.

The film combines real website examples, browser captures and an illustrated workflow: cinematic scroll, interactive depth, real-time 3D, plus desktop, mobile and reduced-motion views.

Install the collection:
