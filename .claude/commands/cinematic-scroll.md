# /cinematic-scroll

Build cinematic, scroll-driven websites with the **`cinematic-scroll`** skill:
pinned chapter reveals, hero and multi-depth parallax, scroll-linked 3D tilt and
camera moves, environment-morphing backgrounds, from a single self-contained
`.html` section to a full Next.js release site. The motion grammar is the
constant; the aesthetic is always the user's.

## When this fires

Use it when the request is for a scroll-driven or "cinematic" site, pinned or
sticky chapter sections, hero or multi-depth parallax, scroll-linked 3D tilt or
camera moves, an environment-morphing layout, a product story page, an editorial
commerce microsite, or a release/launch page.

## Trigger

> Use cinematic-scroll to build a self-contained HTML pinned hero chapter for [YOUR BRAND].

## Do this

Read the skill contract before building; do not work from this pointer alone:

1. Read [`skills/cinematic-scroll/SKILL.md`](../../skills/cinematic-scroll/SKILL.md)
   in full. It routes to one recipe in
   [`skills/cinematic-scroll/references/`](../../skills/cinematic-scroll/references/).
2. When the page strategy is unclear, run
   [`skills/launch-page-strategy/SKILL.md`](../../skills/launch-page-strategy/SKILL.md)
   first; to review an existing page, use
   [`skills/scroll-audit/SKILL.md`](../../skills/scroll-audit/SKILL.md).
3. Pull toolkit references from [`references/`](../../references/) only for a
   concrete gap: `scroll-patterns.md`, `film-archetypes.md`,
   `performance-budget.md`, `mobile-motion.md`.
4. Enforce [`taste-guardrails.md`](../../taste-guardrails.md) on every output and
   verify with `node tools/verify/verify-build.mjs <file> --phase polish`.
