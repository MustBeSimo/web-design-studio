# Web Design Studio — LinkedIn promo

`web-design-studio-linkedin.mp4` is the current 1920×1080 LinkedIn film. It shows
the skill's workflow and real outputs: direction from a brief, distinct visual
systems, real-time 3D, resilience states, and browser evidence. It is designed to
remain understandable with sound muted.

Render it from the repository root:

```bash
node tools/render-linkedin-promo.mjs
```

The renderer uses FFmpeg plus existing tracked footage. It creates the final MP4
and poster without changing the source clips.

## Caption

AI can generate a website quickly. Giving it direction, taste, and a reliable
finish is still the difficult part.

Web Design Studio gives coding agents a practical design and build process: start
from the brief, choose a visual grammar, build one meaningful interaction, compose
mobile and reduced-motion states, then inspect the result in the browser.

This film shows real examples built with the skill—from editorial systems and
product stories to scroll-linked 3D.
